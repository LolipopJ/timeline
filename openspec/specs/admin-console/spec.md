# admin-console Specification

## Purpose

为已登录管理员提供客户端日常维护入口，在现有身份认证之上集中访问同步与运行日志，并在主动退出或会话失效后立即移除受限内容与管理操作。

## Requirements

### Requirement: 管理员可以打开管理面板

客户端 SHALL 仅在身份确认且处于管理员视角时，在时间线右下角显示一个管理图标按钮。按钮 MUST 具有可访问名称，支持键盘打开，并避开移动端的安全区。面板提供同步、日志和退出登录操作。

#### Scenario: 已登录管理员使用管理面板
- **WHEN** 已登录管理员在管理视角激活右下角的管理图标
- **THEN** 客户端打开管理面板并提供同步、日志和退出登录操作

#### Scenario: 访客或身份尚未确认
- **WHEN** 用户未登录、客户端尚未完成登录状态确认，或管理员已进入访客预览
- **THEN** 客户端不显示可用的管理入口，也不请求同步状态或运行日志

### Requirement: 管理面板适配视口并保持主要操作可用

客户端 SHALL 在桌面以右侧抽屉展示管理面板，在移动端以近全屏面板展示。关闭按钮、同步与日志标签和退出登录 MUST 始终位于固定头部，窄屏允许入口换行。面板打开时 MUST 锁定背景滚动，只允许面板内容区滚动。

#### Scenario: 阅读长日志
- **WHEN** 管理员将面板内容滚动到长日志列表末尾
- **THEN** 管理员仍可在头部关闭面板、切换标签或退出登录

#### Scenario: 在移动端打开或旋转面板
- **WHEN** 管理员在窄屏或移动设备横屏下查看面板
- **THEN** 面板适应可用视口，头部操作仍然可见，较长内容可在面板内滚动

### Requirement: 面板支持键盘操作并保留标签设置

面板 MUST 约束打开期间的键盘焦点，支持键盘切换标签，并可通过面板外部空白处、关闭按钮或 Esc 关闭。常规关闭后焦点 MUST 返回管理图标按钮。切换标签时内容区 SHALL 回到顶部，并保留日志筛选条件和自动刷新设置。

#### Scenario: 点击面板外部空白处
- **WHEN** 管理员在面板外部空白处按下并松开指针
- **THEN** 面板关闭并停止轮询，焦点返回管理图标按钮

#### Scenario: 用键盘操作面板
- **WHEN** 管理员使用键盘打开面板、切换标签并按 Esc
- **THEN** 键盘可以访问面板操作，关闭后焦点回到管理图标按钮

#### Scenario: 从日志切换到同步再返回
- **WHEN** 管理员设置日志筛选条件或暂停自动刷新，然后切换到同步并返回日志
- **THEN** 日志内容从顶部显示，仍使用原筛选条件和自动刷新设置

### Requirement: 管理接口独立校验真实身份

后端 MUST 对读取同步状态、触发同步和读取日志分别校验有效管理员会话。客户端视角参数、界面状态或管理入口可见性 MUST NOT 授予管理权限；管理响应 MUST 禁止被 HTTP 缓存复用。

#### Scenario: 未登录或会话失效后直接调用管理接口
- **WHEN** 没有有效管理员会话的请求访问任一管理接口
- **THEN** 后端返回 HTTP 401，不返回受限状态或日志，也不启动同步

#### Scenario: 服务端未启用管理员功能
- **WHEN** 未配置有效管理员功能的服务端收到管理接口请求
- **THEN** 后端沿用现有行为返回 HTTP 400 与“管理员功能未启用”，不返回受限数据或启动同步

#### Scenario: 管理员处于访客预览
- **WHEN** 有效管理员会话通过客户端切换为访客预览
- **THEN** 后端会话仍有效，预览状态只影响展示与时间线读取范围

### Requirement: 管理员可以明确退出登录

客户端 SHALL 提供退出登录操作，通过现有退出接口撤销 Cookie；仅在请求成功后确认退出。成功退出 MUST 关闭管理界面、停止管理刷新、移除受限缓存，并重新展示公开时间线；请求失败 MUST 明确提示且允许重试。

#### Scenario: 成功退出
- **WHEN** 管理员点击退出登录且后端确认成功
- **THEN** 管理入口、日志、同步详情与私密时间线内容立即从当前界面移除，随后按访客权限读取公开数据

#### Scenario: 退出请求失败
- **WHEN** 退出请求因网络或服务端错误失败
- **THEN** 客户端显示失败提示，不宣称退出成功，也不将未确认的退出当作成功状态

### Requirement: 登录失效后停止展示受限数据

客户端 MUST 在管理请求返回 HTTP 401，或登录状态被确认失效时，关闭管理界面、停止轮询、清理访客预览状态及受限缓存，并切换为公开时间线。失效前发出的延迟响应 MUST NOT 再次填充当前界面的受限数据。

#### Scenario: 查看日志时会话过期
- **WHEN** 日志刷新返回 HTTP 401
- **THEN** 客户端关闭管理面板并停止自动刷新，不再展示先前读取的日志或私密时间线项

#### Scenario: 退出后旧请求才返回
- **WHEN** 管理员已退出，而退出前发出的日志、同步状态或时间线请求随后完成
- **THEN** 该响应不会在当前访客界面中恢复任何受限内容
