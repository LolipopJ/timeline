# Spec Delta

## Purpose

让读者在现有个人时间线中清楚辨认不同平台的游戏完成里程碑，通过游戏封面、准确的奖杯名称与实际完成日期获得一致的阅读体验，同时确保合并后的列表、数量、搜索和隐私结果一致，并适配现有主题及移动视口。

## ADDED Requirements

### Requirement: 客户端只接收明确的成就展示数据

时间线响应 SHALL 提供具有共享契约的成就展示信息，包含平台、平台游戏标识、里程碑类型及可确定的达成时数量。封面、游戏名称、链接和日期 SHALL 沿用时间线已有展示字段。响应 MUST NOT 暴露原始平台响应、授权材料或内部同步状态；所有日期 MUST 为 ISO 字符串。

#### Scenario: 客户端读取成就条目

- **WHEN** 时间线接口返回奖杯或全成就项
- **THEN** 客户端能从明确的展示字段渲染卡片，无需解析服务端内部 metadata

### Requirement: 合并后的列表与统计结果一致

合并的全成就项 SHALL 在公开和管理员时间线的列表、分页、按 ID 查询及总数中采用同一展示规则，不作为第二条可见结果。搜索、来源筛选、私密和软删除条件 MUST 在分页与计数前一致应用；新增成就来源 MUST 支持现有的分享与来源菜单。

#### Scenario: 白金与全成就合并

- **WHEN** 两个里程碑被判定为同次完成并合并
- **THEN** 列表只返回本体项，总数只增加一条，分页不会出现客户端过滤造成的空位

#### Scenario: 访客打开私密成就链接

- **WHEN** 访客通过分享链接按 ID 查询私密成就项
- **THEN** 列表为空且总数为零，不泄露封面、游戏名或成就信息

#### Scenario: 通过游戏名称和来源筛选

- **WHEN** 读者搜索游戏名称并选择某个已配置的成就来源
- **THEN** 列表与总数返回该来源下符合可见性条件的对应游戏里程碑

### Requirement: 卡片清楚表达平台与里程碑

成就卡片 SHALL 展示游戏封面、名称、平台图标与文字、里程碑名称，并可展示已验证的达成时成就数量。白金、Mythic、本体全成就和全成就 MUST 使用正确文字区分；卡片 MUST NOT 仅靠颜色传达类型，也 MUST NOT 把历史完成数据表达为当前实时进度。

#### Scenario: 展示三个平台的里程碑

- **WHEN** 时间线分别显示 PSN 白金、Xbox Mythic 与 Steam 全成就
- **THEN** 各卡片显示对应平台和真实里程碑名称，沿用统一的时间线头部及菜单

#### Scenario: 游戏完成后新增未完成成就

- **WHEN** 历史全成就项仍然可见，但游戏当前已有未完成追加内容
- **THEN** 卡片展示原完成日期及明确属于达成时的数量，不声称当前仍为全部完成

#### Scenario: 封面不可用

- **WHEN** 来源没有可用封面或图片加载失败
- **THEN** 卡片保留稳定的封面占位、可读游戏名、平台及里程碑信息

### Requirement: 卡片适配现有主题与窄屏

成就卡片 SHALL 沿用现有水墨深色与纸张浅色主题，在桌面突出封面和里程碑，在窄屏调整封面尺寸并允许长标题换行。卡片 MUST 保持纵向阅读，无水平溢出，日期与来源继续服从既有时间线布局，图片保持原色。

#### Scenario: 移动端阅读长标题

- **WHEN** 读者在 360px 宽度视口查看较长游戏名称的成就项
- **THEN** 名称、平台和里程碑均可辨认，卡片不会造成页面水平滚动

#### Scenario: 切换主题

- **WHEN** 读者在任一身份或视角切换主题
- **THEN** 成就卡片立即沿用当前主题，正文、徽章、边界和焦点清晰可辨，游戏图片保留原色

### Requirement: 卡片交互支持键盘与减少动态效果

成就卡片中的链接与既有菜单 SHALL 支持键盘操作及可辨认焦点。信息 MUST NOT 依赖悬停才可见；装饰图标 MUST NOT 造成重复朗读。视觉反馈 SHALL 遵守减少动态效果偏好，MUST NOT 使用持续闪烁或持续庆祝动画。

#### Scenario: 使用键盘打开游戏成就链接

- **WHEN** 读者通过 Tab 聚焦并激活卡片提供的链接
- **THEN** 焦点可见，链接具有明确的可访问名称，并打开对应平台的游戏或成就页面

#### Scenario: 用户偏好减少动态效果

- **WHEN** 系统启用了减少动态效果
- **THEN** 卡片仍完整显示里程碑信息，不依赖移动、缩放或闪光表达完成状态
