# Proposal

## Why

当前客户端已具备「数字档案册」布局与「水墨深色 / 纸张浅色」双主题基底，但在首屏加载阶段存在三段式布局跳变，长文折叠、多媒体走马灯及条目管理确认等交互较为生硬，且主题切换、轴线游标和浮层缺少细腻的过渡反馈。系统性打磨客户端界面细节并引入克制的动态效果，能够消除交互断层、强化纸墨档案的呼吸感与空间连续性。

## What Changes

- **稳定首屏与列表加载质感**：在确认登录状态、加载筛选来源和首屏时间线数据期间，直接渲染稳定的「侧栏/顶栏 + 装订线」档案骨架屏，消除三段式文字跳变；新加载或筛选更新的时间线项在 `motion-safe` 下呈现轻柔的上浮淡入过渡。
- **装订线游标联动与年份翻页**：悬停或键盘聚焦时间线项时，同步点亮并微放大左侧装订线圆点刻度、提亮桌面端时间戳；`TimelineCurrentDate` 跨年滚动时为中文大写年份增加与月份一致的立式淡入淡出动画。
- **主题扩散切换与卡片边界层次**：在支持 View Transitions API 且未启用减少动态效果的浏览器中，点击主题切换按钮时从按钮位置向外执行平滑扩散过渡；为常规时间线内容卡片补充适配双主题的细微 `ring-binding` 内描边，提升纸张浅色与水墨深色下的卡片边界辨识度。
- 长文折叠时显示底部渐隐遮罩，展开和收起使用整行可点击的图标按钮，收起时恢复折叠高度与阅读位置。Bilibili 卡片以底部渐变浮层呈现标题与简介，标题以全角起始标点开头时通过负行首外边距对齐简介，封面在悬停时微缩放。`Slideshow` 支持触摸滑动、常驻页码指示及前后切换引导。
- **内联二次确认与弹窗规范化**：将条目菜单中的「设为私密 / 设为公开」和「删除」由浏览器原生 `window.confirm` 改为菜单内联二次确认；将 `LoginModal` 升级为原生 `<dialog>` 模态框，并为回顶按钮、导航下拉菜单及 `AdminConsole` 抽屉补齐显隐过渡。

## Capabilities

### New Capabilities
- `timeline-item-interaction`: 时间线单条内容的长文展开与收起、Bilibili 封面卡片与走马灯多媒体触控交互，以及条目管理操作（设为私密/公开、删除）的菜单内联二次确认。

### Modified Capabilities
- `timeline-navigation`: 增加首屏与列表加载的档案骨架结构、条目分页/筛选入场过渡、装订线刻度与时间戳的悬停/聚焦联动、当前阅读年份的滚动切换过渡，以及回顶按钮和工具栏下拉菜单的显隐过渡。
- `display-theme`: 增加主题切换时的扩散过渡效果（支持减少动态效果与浏览器回退），并明确时间线正文卡片在双主题下的装订线内描边层次。
- `admin-console`: 将管理员登录界面升级为原生 `<dialog>` 模态框（统一键盘焦点、Esc 与背景关闭交互），并为管理面板抽屉与登录弹窗增加开关过渡动效。

## Impact

- 主要影响 `client/src/app/`（`layout.tsx`、`globals.css`）、`client/src/styles/animation.css` 及 `client/src/components/` 下的时间线、搜索菜单、工具栏、主题切换、折叠容器、走马灯、各来源卡片、登录弹窗与管理面板组件。
- 涉及 `client/e2e/admin-tools.spec.mts` 中针对条目私密切换（由原生 `dialog` 确认更新为菜单内联确认）、长文展开收起、主题切换及新增交互的端到端测试更新。
- 保持 Next.js 静态导出（`output: "export"`），不改动服务端接口或 `@timeline/contracts` 契约，不引入新的重型动画运行时依赖。
