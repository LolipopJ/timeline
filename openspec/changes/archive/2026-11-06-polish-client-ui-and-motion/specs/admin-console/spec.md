# Spec Delta

## ADDED Requirements

### Requirement: 管理员登录弹窗采用原生模态对话框与键盘约束

当访问携带 `login` 查询参数的页面时，客户端 SHALL 使用原生模态 `<dialog>` 渲染管理员登录弹窗，提供明确的可访问名称与关闭按钮，约束打开期间的键盘焦点，并支持通过关闭按钮、按下 Esc 或在对话框外部背景处点击关闭弹窗。关闭弹窗后客户端 MUST 移除 URL 中的 `login` 参数。

#### Scenario: 通过键盘或背景关闭登录弹窗

- **WHEN** 用户打开 `/?login` 呼出管理员登录弹窗，随后按下 Esc、点击关闭按钮或点击对话框外部背景
- **THEN** 登录模态对话框关闭，URL 恢复为不含 `login` 参数的路径

#### Scenario: 提交管理员登录表单

- **WHEN** 用户在登录模态对话框中填写用户名与密码并提交
- **THEN** 客户端向 `/login` 提交凭据并在成功后进入已登录管理状态

### Requirement: 管理面板与登录弹窗具备平滑显隐过渡

在未启用系统减少动态效果时，桌面端右侧管理面板抽屉 SHALL 以水平滑入与背景遮罩淡入方式打开，移动端管理面板与管理员登录弹窗 SHALL 以微缩放及淡入方式打开。启用系统减少动态效果时，管理面板与登录弹窗 MUST 直接显示而不播放位移动画。

#### Scenario: 打开管理面板抽屉

- **WHEN** 已登录管理员点击右下角管理面板按钮打开面板
- **THEN** 面板及其背景遮罩按当前视口形态平滑过渡展现（减少动态效果下直接呈现），且内部控件立即可交互
