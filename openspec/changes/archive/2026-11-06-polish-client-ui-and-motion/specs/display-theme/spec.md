# Spec Delta

## ADDED Requirements

### Requirement: 主题切换提供平滑的视图扩散过渡

当读者激活主题切换控件时，在支持 View Transitions API 且未启用系统减少动态效果的浏览器中，客户端 SHALL 以切换按钮为起点执行平滑的主题扩散过渡动画，同时立即更新根节点主题属性与本地存储记录，并保持键盘焦点与当前滚动位置不变。当浏览器不支持该接口或用户启用了减少动态效果时，客户端 MUST 直接完成主题切换而不播放扩散动画。

#### Scenario: 常态下点击切换主题

- **WHEN** 用户在未启用减少动态效果的现代浏览器中点击或按键盘激活主题切换按钮
- **THEN** 根节点立即应用目标主题并触发视图扩散过渡，按钮焦点与页面滚动位置保持不变

#### Scenario: 启用减少动态效果时切换主题

- **WHEN** 用户启用系统减少动态效果并激活主题切换按钮
- **THEN** 页面直接切换为目标主题并写入本地存储，不播放视图扩散动画

### Requirement: 正文卡片在双主题下具备装订线内描边层次

时间线中的正文与媒体卡片（包括博客文章、GitHub 评论、QQ 空间说说、Steam 评测、Bilibili 封面卡片及游戏成就卡片）SHALL 使用随当前主题变化的装订线色（`binding`）呈现细微的卡片边界描边，使阅读表面在水墨深色与纸张浅色页底上均具有清晰的卡片轮廓层次。

#### Scenario: 在纸张浅色与水墨深色下浏览卡片边界

- **WHEN** 读者在纸张浅色或水墨深色主题下浏览不同来源的时间线卡片
- **THEN** 各类卡片表面与页面背景之间均有可辨认的低对比装订线色边界，且不遮挡内部正文与媒体
