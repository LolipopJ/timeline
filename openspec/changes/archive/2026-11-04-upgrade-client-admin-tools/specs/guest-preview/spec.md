# Spec Delta

## Purpose

让管理员在保持真实登录会话的前提下，查看与未登录访客相同的公开时间线，并保证切换视角时搜索、分页、总数与客户端缓存使用一致的可见性范围，便于确认站点公开内容。

## ADDED Requirements

### Requirement: 管理员可以在保留会话的情况下切换视角

客户端 SHALL 为已登录管理员提供访客预览开关，保留登录 Cookie 与真实管理员身份，且不调用退出接口。预览期间 MUST 显示明确的预览标识与返回管理员视角入口；返回时 MUST 无需重新登录。

#### Scenario: 进入并退出访客预览
- **WHEN** 管理员进入访客预览后再返回管理员视角
- **THEN** 两次切换均不撤销登录会话，返回后仍可使用管理员功能

### Requirement: 公开可见性在后端查询阶段生效

时间线列表与总数接口 SHALL 接受 `view=public|admin`。显式 `public` MUST 仅查询公开内容；`admin` 或省略参数 MUST 按真实身份决定是否可见私密内容，未登录用户不能借参数获得权限。未知视角值 MUST 返回 HTTP 400。公开可见性 MUST 在搜索、排序、分页和计数前生效，且相关响应 MUST 禁止 HTTP 缓存复用。

#### Scenario: 管理员请求公开视角
- **WHEN** 有效管理员会话使用 `view=public` 查询列表和总数
- **THEN** 两个接口均排除私密内容，返回结果与同条件下未登录访客查询一致

#### Scenario: 分页中混有大量私密项
- **WHEN** 管理员在访客预览中分页查询，而时间顺序中存在大量私密项
- **THEN** 后端先排除私密项再分页，结果不会因为先取私密项再过滤而出现错误的空页或提前结束

#### Scenario: 搜索只命中私密内容
- **WHEN** 访客预览使用仅匹配私密内容的关键词查询列表和总数
- **THEN** 列表为空且总数为零，不通过数量、页数或年份分组泄露私密内容

#### Scenario: 未登录用户请求管理员视角
- **WHEN** 未登录用户传入 `view=admin`
- **THEN** 后端仍只返回公开内容，不因该参数提升权限

### Requirement: 切换视角不会残留上一范围的数据

客户端 MUST 按真实登录身份与当前视角隔离时间线及管理数据缓存。切换时 MUST 立即移除上一视角的已渲染数据、重置分页与进度，并重新读取列表及总数；旧视角的延迟响应 MUST NOT 写入当前视角。搜索和服务筛选条件 SHALL 保留。

#### Scenario: 已加载私密内容后进入预览
- **WHEN** 管理员已经加载多页内容，然后进入访客预览
- **THEN** 旧列表立即移除，按公开视角从第一页重新读取，加载期间也不展示私密项或管理员总数

#### Scenario: 切换后旧请求返回
- **WHEN** 进入公开视角后，旧管理员视角的分页请求才返回
- **THEN** 当前公开列表、总数及进度均不受该响应影响

#### Scenario: 带筛选返回管理员视角
- **WHEN** 管理员在有搜索和服务筛选条件的预览中返回管理员视角
- **THEN** 保留这些筛选条件，重新读取管理员范围的数据并从第一页开始展示

### Requirement: 预览隐藏内容管理操作

访客预览期间客户端 MUST 隐藏设为私密、设为公开、删除、恢复等内容管理操作，并关闭同步或日志面板及其轮询。返回管理员视角和退出登录入口 SHALL 保持可用；预览状态 MUST 与真实登录状态分别维护。

#### Scenario: 预览公开时间线项
- **WHEN** 已登录管理员正在访客预览中查看公开条目
- **THEN** 条目只提供访客可用的阅读或来源链接操作，不展示任何修改或删除操作

#### Scenario: 预览期间会话失效
- **WHEN** 客户端确认管理员会话已经失效
- **THEN** 清理预览及管理员状态，继续按真实访客权限读取公开内容，不再显示返回管理员视角入口
