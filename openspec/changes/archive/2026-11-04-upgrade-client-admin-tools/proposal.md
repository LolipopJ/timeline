# Proposal

## Why

管理员目前主要依赖 URL 参数登录，以及直接访问后端或查看进程控制台来维护站点，无法在客户端触发同步、确认执行结果或查看日志。需要在保留管理员登录态的同时预览访客可见内容，让日常维护与公开内容检查在客户端完成。

## What Changes

- 为已登录管理员增加右下角管理图标和响应式管理面板，在固定头部集中提供同步、日志、访客预览与显式退出登录操作，复用现有登录验证。
- 手动触发所有已启用服务的一轮同步，沿用现有增量和服务级 `full` 配置；展示运行状态、最近一次整体及逐服务执行结果。手动、定时和启动同步共享并发限制与状态记录。
- 查看当前后端进程的最近日志，按时间从新到旧展示，支持级别、模块、文本筛选与自动刷新。日志使用有容量上限的内存缓存，重启后清空，读取前后的记录均须脱敏。
- 时间线向下滚动超过一屏后，所有读者均可使用右下角的回顶图标。
- 提供访客预览开关：保留 Cookie 登录态，由服务端过滤私密内容，列表、搜索、总数与分页采用同一可见性规则；预览期间隐藏内容管理操作，并提供返回管理员视角入口。
- 登录失效或主动退出时，停止管理请求并清除界面中的受限数据，防止客户端缓存继续展示管理员内容。
- 本次不包含在线编辑服务配置、管理账号、日志文件持久化、按服务重试、手动全量同步、取消任务或独立管理站点。

## Capabilities

### New Capabilities

- `admin-console`：管理员面板、访问控制、退出登录与登录失效后的界面清理。
- `sync-operations`：手动同步、统一防重入、运行状态及最近执行结果。
- `runtime-logs`：受权限保护、可筛选且容量受限的当前进程日志查看。
- `guest-preview`：保留管理员会话的访客可见性预览及缓存隔离。
- `timeline-navigation`：公开时间线的回顶图标、悬浮入口排列与减少动态效果设置。

### Modified Capabilities

无。当前仓库刚初始化 OpenSpec，尚无既有能力规格；上述规格覆盖本次新增或改变的行为。

## Impact

- 客户端：`client/src/app/layout.tsx`、`contexts/GlobalContext.ts`、`components/TimelineHome`、`components/TimelineItemLabel`，以及新增管理面板与请求封装；沿用 React、SWR、Axios 和现有样式体系。
- 后端：`server/src/index.ts` 的权限校验、时间线查询及同步生命周期，`server/src/sync/index.ts`、QQ 空间的前置失败处理、`server/src/utils/logger.ts`；管理接口处理与日志缓存由独立模块承载，同步状态归同步协调模块所有。
- 共享契约：在 `packages/contracts/src` 定义管理员同步、日志 DTO 与时间线视角查询参数；新增 `/admin/sync`、`/admin/logs` 接口，扩展时间线列表与总数接口。
- 文档：更新 README 的管理员操作说明与内存日志保留限制。不新增运行时依赖或数据库表，不建立旧实现的兼容分支；客户端与后端一起发布。
