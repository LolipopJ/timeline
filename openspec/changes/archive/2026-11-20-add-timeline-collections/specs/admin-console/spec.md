# Spec Delta

## MODIFIED Requirements

### Requirement: 管理员可以打开管理面板

客户端 SHALL 仅在身份确认且处于管理员视角时，在时间线右下角显示一个管理图标按钮。按钮 MUST 具有可访问名称，支持键盘打开，并避开移动端的安全区。面板 SHALL 提供同步、日志、合集标签和退出登录操作。

#### Scenario: 已登录管理员使用管理面板
- **WHEN** 已登录管理员在管理视角激活右下角的管理图标
- **THEN** 客户端打开管理面板并提供同步、日志、合集标签和退出登录操作

#### Scenario: 访客或身份尚未确认
- **WHEN** 用户未登录、客户端尚未完成登录状态确认，或管理员已进入访客预览
- **THEN** 客户端不显示可用的管理入口，也不请求同步状态、运行日志或用于管理的完整合集树

### Requirement: 管理面板适配视口并保持主要操作可用

客户端 SHALL 在桌面以右侧抽屉展示管理面板，在移动端以近全屏面板展示。关闭按钮、同步、日志与合集标签和退出登录 MUST 始终位于固定头部，窄屏允许入口换行。面板打开时 MUST 锁定背景滚动，只允许面板内容区滚动。

#### Scenario: 阅读长日志
- **WHEN** 管理员将面板内容滚动到长日志列表末尾
- **THEN** 管理员仍可在头部关闭面板、切换标签或退出登录

#### Scenario: 在移动端打开或旋转面板
- **WHEN** 管理员在窄屏或移动设备横屏下查看面板
- **THEN** 面板适应可用视口，头部操作仍然可见，较长内容可在面板内滚动
