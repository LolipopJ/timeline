# Proposal

## Why

Timeline 可以按来源和关键词查找条目。读者需要按主题整理横跨不同来源的内容，并在保留同一条目多种归属的同时浏览一个主题下的全部内容。

## What Changes

- 在管理面板新增「合集」标签页，提供固定的「全部」根节点、子合集创建和拖拽移动。移动一个合集时，其完整子树随之移动。
- 在管理视角的条目菜单新增「编辑合集」。管理员可以在树中为条目选择多个合集，勾选子级自动勾选祖先，取消父级清除该分支的勾选。
- 时间线支持选择单个合集筛选，并纳入该合集全部后代的条目。筛选保存在 URL 中，可与来源、关键词和排序一起使用。
- 条目卡片展示该条目归属路径上最深的合集名称。访客及访客预览按公开条目的可见性浏览合集树。

## Capabilities

### New Capabilities

- `timeline-collections` 提供合集树、条目多重归属、按合集子树查询以及条目合集标签。

### Modified Capabilities

- `admin-console` 将「合集」纳入管理面板的入口和固定标签栏。
- `timeline-search` 在 URL 筛选状态中加入合集，并扩展单条 ID 条件的互斥规则。

## Impact

- 服务端增加合集和归属存储、树读取及管理接口。时间线列表和总数共用合集条件，条目 DTO 增加可展示的合集名称。
- 客户端扩展管理面板、条目菜单和时间线筛选入口，沿用现有静态导出、Cookie 鉴权和视角缓存规则。
- 共享契约增加合集 DTO、归属编辑请求及列表和计数的合集参数。
