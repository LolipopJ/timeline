# 搜索与分享

搜索框中的普通文字按关键词匹配时间线的标题或正文。关键词输入在停顿 500ms 后更新 URL；键入条件后按空格或 Enter 确认，粘贴完整条件、删除标签、选择「只看当前类型」或切换排序会立即更新。输入法组词期间保留草稿，不提交 URL。界面更新当前历史记录，不为每次输入新增历史条目；直接打开链接、刷新以及在已有历史记录间前进或后退时，搜索框、排序和结果均由当前 URL 恢复。

点击搜索框可查看来源标签。同名标签只显示一次。选择标签会清除当前关键词和 ID 条件，显示该标签下所有来源的可见条目。选中的标签显示为 `类型: 成就奖杯`，可点击移除。

## 条件语法

| 输入                                      | 行为                           |
| ----------------------------------------- | ------------------------------ |
| `旅行`                                    | 搜索标题或正文中的关键词       |
| `type:MyBlog`                             | 查看显示标签为 `MyBlog` 的内容 |
| `type:Lolipop's Thoughts`                 | 支持标签中的空格与撇号         |
| `旅行 type:MyBlog`                        | 在该来源内搜索关键词           |
| `id:6f1e6c1a-6a1f-4b0e-8f3f-2a1e3f6c9d10` | 精确查看对应的单条时间线项     |

`type:` 后填写完整的来源显示标签。来源未配置标签或已从配置中移除时，以服务 ID 作为显示标签。解析时优先匹配最长的已知标签。含空格的条件可按 Enter 确认。客户端从公开的 `GET /timeline-services` 获取去重后的标签字符串数组，其中包含配置的来源标签和当前视角下可见条目的历史来源。清单加载失败时可以点击「重试加载」。

确认后的 ID 或类型条件会显示为可删除标签，点击标签立即移除对应筛选。确认前保留完整文本，避免将 `type:MyBlogExtra` 提前识别成 `type:MyBlog`。ID 与关键词、类型互斥：新输入 ID 时清空其它条件，输入关键词或类型时清除 ID。一次输入多种互斥条件时按从左到右的顺序处理，后写入的条件生效。`id:hello`、未知的 `type:` 值和未完成的条件均按普通关键词搜索。

## 链接与条目菜单

点击条目的来源名称可打开菜单，按「打开链接」「复制分享链接」「只看当前类型」排列；没有原始链接时不显示「打开链接」。所有读者均可使用「复制分享链接」，将包含该条目 ID 条件的完整链接写入剪贴板；复制成功或失败都保留当前 URL、筛选和结果，并显示相应反馈。私密条目也提供分享入口，但未登录访客或访客预览打开分享链接时只会看到「没有找到相关内容」，管理员可以查看。

「只看当前类型」会立即用该条目的显示标签筛选同名来源，保留当前输入的关键词（包括尚未提交的草稿）并清除 ID。排序菜单可选择创建时间或更新时间；没有指定排序时按创建时间排列。

以下链接以本地开发地址为例，ID 及来源标签需替换为当前实例中的值：

- [单条时间线项](http://127.0.0.1:3000/?search=id%3A6f1e6c1a-6a1f-4b0e-8f3f-2a1e3f6c9d10)
- [在 MyBlog 来源中搜索旅行并按更新时间排列](http://127.0.0.1:3000/?search=%E6%97%85%E8%A1%8C%20type%3AMyBlog&orderBy=updated_at)

URL 使用 `search` 表达关键词和条件，使用 `orderBy=updated_at` 表达更新时间排序；未知参数不参与筛选。来源筛选统一使用 `search` 内的 `type:` 条件。
