# 搜索与分享

搜索框中的普通文字按关键词匹配时间线的标题或正文。关键词输入在停顿 500ms 后更新 URL；键入条件后按空格或 Enter 确认，粘贴完整条件、删除标签、选择「只看当前类型」或切换排序会立即更新。输入法组词期间保留草稿，不提交 URL。每次提交不同的筛选状态会新增一条浏览记录。直接打开链接、刷新以及前进或后退时，搜索框、合集、排序和结果均由当前 URL 恢复。

点击搜索框可查看来源标签。同名标签只显示一次。选择标签会清除当前关键词和 ID 条件，显示该标签下所有来源的可见条目。选中的标签显示为 `类型: 成就奖杯`，可点击移除。

## 条件语法

| 输入                                      | 行为                           |
| ----------------------------------------- | ------------------------------ |
| `旅行`                                    | 搜索标题或正文中的关键词       |
| `type:MyBlog`                             | 查看显示标签为 `MyBlog` 的内容 |
| `type:Lolipop's Thoughts`                 | 支持标签中的空格与撇号         |
| `旅行 type:MyBlog`                        | 在该来源内搜索关键词           |
| `id:6f1e6c1a-6a1f-4b0e-8f3f-2a1e3f6c9d10` | 精确查看对应的单条时间线项     |

`type:` 后填写完整的来源显示标签。来源未配置标签或已从配置中移除时，以服务 ID 作为显示标签。解析时优先匹配最长的已知标签。含空格的条件可按 Enter 确认。客户端从公开的 `GET /timeline-services` 获取去重后的标签字符串数组，其中包含配置的来源标签和当前视角下可见条目的历史来源。清单加载失败时可以点击「重试加载」。

确认后的 ID 或类型条件会显示为可删除标签，点击标签立即移除对应筛选。确认前保留完整文本，避免将 `type:MyBlogExtra` 提前识别成 `type:MyBlog`。ID 与关键词、类型、合集互斥。提交 ID 时会清空其他筛选，输入关键词或类型、选择非根合集时会清除 ID。链接同时包含合法 ID 和合集时，按 ID 查询。一次输入多种互斥条件时按从左到右的顺序处理，后写入的条件生效。`id:hello`、未知的 `type:` 值和未完成的条件均按普通关键词搜索。

## 合集

点击时间线工具区的「筛选合集」可以浏览合集树。选择父级时，列表包括直接加入该合集的条目及其所有子合集中的条目，并继续应用关键词、来源和排序。选择「全部」会清除合集筛选，也能看到尚未归类的条目。合集筛选保存在 URL 的 `collectionId` 中，可随链接分享。

筛选树和管理面板会显示每个合集的可见条目数。「全部」也计入未归类的条目，父合集统计整支树，同一条目只计一次。
这些数量随访客或管理员视角变化，独立于关键词和来源筛选。同级合集按数量从多到少排列，数量相同时按名称排序。

访客和访客预览只能看到含公开条目的合集及其祖先。若链接指向当前视角无法浏览的合集，工具区显示「合集不可用」。管理员视角下，会话失效后的下一次时间线读取会切换到访客范围并重新判定合集可用性。选择「全部」可清除合集筛选。

管理员可以在「管理面板」的「合集」标签下创建子合集。拖动合集或选择「移动到…」可以把整个分支移到新的父级，包括「全部」。在条目的来源菜单中选择「编辑合集」，可同时选择多个分支。勾选子级会点亮祖先，取消父级会清除该分支的选择。卡片展示条目各归属分支中层级最深的合集名称。

## 链接与条目菜单

点击条目的来源名称可打开菜单，按「打开链接」「复制分享链接」「只看当前类型」排列；没有原始链接时不显示「打开链接」。所有读者均可使用「复制分享链接」，将包含该条目 ID 条件的完整链接写入剪贴板；复制成功或失败都保留当前 URL、筛选和结果，并显示相应反馈。私密条目也提供分享入口，但未登录访客或访客预览打开分享链接时只会看到「没有找到相关内容」，管理员可以查看。

「只看当前类型」会立即用该条目的显示标签筛选同名来源，保留当前输入的关键词（包括尚未提交的草稿）并清除 ID，已选合集继续生效。排序菜单可选择创建时间或更新时间；没有指定排序时按创建时间排列。

管理员可以从任一条目的来源菜单进入「多选」。当前条目会自动选中，滚动加载更多条目后仍可继续勾选。页面顶部显示选中数量，可「编辑合集」「设为私密」或「删除」。设为私密和删除需要在弹窗中确认，取消确认可以继续选择。批量编辑合集可添加到所选合集，也可从所选合集及其子合集移出，其他归属保留。操作成功、退出多选、切换筛选或离开管理员视角时会清空选择。

以下链接以本地开发地址为例，ID 及来源标签需替换为当前实例中的值：

- [单条时间线项](http://127.0.0.1:3000/?search=id%3A6f1e6c1a-6a1f-4b0e-8f3f-2a1e3f6c9d10)
- [在 MyBlog 来源中搜索旅行并按更新时间排列](http://127.0.0.1:3000/?search=%E6%97%85%E8%A1%8C%20type%3AMyBlog&orderBy=updated_at)

URL 使用 `search` 表达关键词和条件，使用 `orderBy=updated_at` 表达更新时间排序；未知参数不参与筛选。来源筛选统一使用 `search` 内的 `type:` 条件。
